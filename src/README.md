# ubem-mcp-server

The Python package of [UBEM-MCP](https://github.com/TensorBuildLab/UBEM-MCP): an MCP server, Python library and command line for urban building energy modeling data and simulation with EnergyPlus.

See the [repository README](https://github.com/TensorBuildLab/UBEM-MCP#readme) for installation, the tool list and worked examples.
