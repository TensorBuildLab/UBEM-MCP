# Archetype data

These files are generated by scripts in `src/scripts/` from public U.S. Department of Energy data. Do not edit them by hand; rerun the scripts instead. Each file records its source URLs and the SHA-256 hash of every input file.

## What is extracted

**Commercial (per building type and vintage):**
- floor area, number of floors, floor-to-floor height, window-to-wall ratio
- area-weighted internal loads (people, lighting, electric and gas plug/process loads, service hot water, outdoor air, infiltration)
- HVAC system description and water-heater efficiency
- hourly schedules mapped to roles (occupancy, lighting, equipment, setpoints, infiltration, HVAC operation, hot water)

**Commercial (per climate zone):**
- wall, roof and floor R-values
- window U-factor, SHGC and visible transmittance
- cooling COP, heating efficiency and economizer
- the reference simulation's end-use energy intensities, used by `scripts/validate_archetypes.py`

**Single-family:**
- per climate zone: envelope U-factors, window properties, HVAC efficiencies, effective leakage area and reference end-use intensities
- once, since they are the same in every zone: appliance-level internal loads, schedules, thermostat setpoints and hot-water fixtures

Modeling assumptions made on top of these data, such as older single-family vintages taking the mid-rise apartment's envelope, are listed in `ubem_mcp_server/urban/library.py`. They are also recorded per building in every generated model set's `manifest.json`.
